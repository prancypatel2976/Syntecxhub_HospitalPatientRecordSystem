# Hospital Patient Record System

A web-based Hospital Patient Record System developed using Java, Hibernate, MySQL, JSP, Servlets, HTML, and CSS.

## Features

* Admin Login
* Add New Patient
* View Patient Records
* View Patient Details
* Update Patient Medical History
* MySQL Database Storage
* Secure Login and Authentication

## Technologies Used

* Java 17
* Hibernate
* MySQL
* JSP
* Servlets
* HTML & CSS
* Apache Tomcat
* Maven
* Eclipse

## Database

Database name:
hospital_db

## How to Run

1. Install Java, Eclipse, MySQL and Apache Tomcat.
2. Create the hospital_db database in MySQL.
3. Update MySQL username/password in the Hibernate configuration.
4. Import the project into Eclipse as a Maven project.
5. Configure Apache Tomcat 10.
6. Run the project on Tomcat.
